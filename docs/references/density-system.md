# Density System

## Default Rhythm
Base: 4px.
Common spacing: 4 / 8 / 12 / 16 / 24 / 32.

## Suggested Density Bands
Compact:
- controls 28–32px
- rows 28–32px
- tight repeated workflows

Default:
- controls 32–36px
- rows 32–40px

Comfortable:
- optional accessibility/preference mode where justified

## Rules
Use padding to establish rhythm, not to decorate. Repeated rows should prioritize scanability. Large empty regions need a functional reason. Dense does not mean cramped: typography, alignment, contrast, grouping, and predictable columns create legibility.
