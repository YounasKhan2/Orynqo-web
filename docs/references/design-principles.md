# Design Principles

1. Density with legibility.
2. Hierarchy before decoration.
3. Objects before pages.
4. Workflows before screens.
5. Reuse before invention.
6. Context preservation before navigation churn.
7. Progressive disclosure before simplification-by-removal.
8. Keyboard and pointer parity for frequent operations.
9. Explicit system status.
10. Predictability beats novelty in repeated workflows.

## Visual Character
Quiet, precise, compact, neutral, fast, and structurally expressive. Let content carry the interface. Use emphasis sparingly so emphasis remains meaningful.

## Anti-patterns
Dashboard-card soup, oversized headings, gratuitous gradients, excessive pills, nested containers, decorative whitespace, inconsistent local components, hidden critical actions, icon-only ambiguity, and duplicated navigation.
