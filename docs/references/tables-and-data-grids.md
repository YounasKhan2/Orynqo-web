# Tables and Data Grids

Tables are preferred when comparison across consistent properties matters.

Specify:
- columns and priority
- min/default/max widths
- resizing
- sticky behavior
- sort
- filter
- grouping
- selection
- row actions
- bulk actions
- editing
- pagination/virtualization
- loading/error/empty
- keyboard navigation
- mobile fallback

Keep high-frequency actions close; move rare actions to overflow. Avoid wrapping critical identifiers into unreadable multi-line rows unless unavoidable.
