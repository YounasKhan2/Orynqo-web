# Application Shell

## Desktop Regions
1. Global/workspace rail or sidebar.
2. Context navigation.
3. Content header.
4. View/action strip.
5. Main content.
6. Optional inspector/detail pane.

## Rules
- Keep shell geometry stable across adjacent workflows.
- Sidebar should collapse without destroying orientation.
- Do not place every destination in primary navigation.
- Put contextual actions near the object they affect.
- Detail panes should be resizable where content complexity warrants it.
- Deep-link meaningful object/detail states when technically feasible.
