# Project Management Patterns

## Common hierarchy
Portfolio/Initiative → Project → Milestone/Cycle → Work item → Subtask.

Use only justified levels.

## Work Item Detail
Common regions:
- title/status
- properties
- description/spec
- sub-items
- dependencies/blockers
- attachments
- comments/activity
- history
- contextual actions

Prefer an inspector/drawer for quick review and a full-page mode for deep work when both are justified.

## Views
List/Table: scanning and bulk work.
Board: state/group movement.
Timeline/Roadmap: temporal relationships.
Calendar: date-based scheduling.
Workload: capacity.
Analytics: aggregate interpretation.
