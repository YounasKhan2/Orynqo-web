# Information Architecture

Use stable nouns for primary navigation. Separate global, workspace, team/project, and object-level navigation.

## IA Rules
- A concept gets one canonical home.
- Navigation depth should reflect domain hierarchy, not org-chart politics.
- Recents/favorites accelerate access; they do not replace canonical IA.
- Search is complementary to navigation.
- Settings should be scoped: personal, workspace/org, team/project, integration/admin.
- Avoid duplicate destinations with different labels.
- Breadcrumbs represent meaningful hierarchy, not browser history.
