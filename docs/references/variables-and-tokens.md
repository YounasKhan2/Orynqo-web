# Variables and Tokens

Use primitive → semantic → component token layering.

## Semantic Categories
- surface: canvas, raised, overlay, selected
- text: primary, secondary, muted, inverse, disabled
- border: subtle, default, strong, focus
- action: primary, secondary, destructive
- status: neutral, info, success, warning, danger
- interaction: hover, pressed, selected, focus

Support light/dark modes through semantics, not duplicated component values.

Spacing, radius, typography, elevation, opacity, motion duration, and easing should also be tokenized where the design environment supports it.
