# Design QA Checklist

## Architecture
- [ ] Correct domain objects
- [ ] Correct relationships
- [ ] Roles/permissions represented
- [ ] Scale assumptions tested

## System
- [ ] Existing components reused
- [ ] Tokens/variables bound
- [ ] No unexplained local styling
- [ ] Density consistent

## Workflow
- [ ] Happy path
- [ ] Validation
- [ ] Loading
- [ ] Empty
- [ ] Errors
- [ ] Permission states
- [ ] Destructive/recovery paths
- [ ] Context preservation

## Interaction
- [ ] Hover/focus/pressed/selected
- [ ] Keyboard behavior
- [ ] Overlay focus behavior
- [ ] Command/shortcut behavior where relevant

## Responsive
- [ ] Desktop
- [ ] Narrow desktop/tablet
- [ ] Mobile strategy
- [ ] Overflow behavior

## Accessibility
- [ ] Contrast
- [ ] Focus
- [ ] Labels
- [ ] Non-color cues
- [ ] Reduced motion
- [ ] Accessible alternatives to pointer gestures

## Handoff
- [ ] Component names
- [ ] Variants/properties
- [ ] Token references
- [ ] Interaction notes
- [ ] Edge cases
- [ ] Open decisions
