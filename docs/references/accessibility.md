# Accessibility

Target WCAG 2.2 AA where applicable.

Checklist:
- keyboard reachability
- visible focus
- correct semantics
- labels/names
- contrast
- status not conveyed by color alone
- zoom/reflow
- overlay focus management
- error association
- accessible drag/drop alternative
- reduced motion
- data table semantics
- sufficient target sizing
- screen reader announcements for meaningful async updates
