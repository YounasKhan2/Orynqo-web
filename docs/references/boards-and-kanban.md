# Boards and Kanban

- Columns represent a meaningful grouping dimension.
- Preserve filtering and saved-view behavior across views.
- Show WIP/count information only when useful.
- Support collapsed groups when scale requires.
- Drag/drop must have keyboard-accessible alternatives.
- Make drop result and invalid destinations explicit.
- Avoid oversized cards; expose only properties needed for board decisions.
- Opening a card should preserve board context.
